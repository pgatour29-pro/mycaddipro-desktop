# MyCaddiPro Tee Sheet for Windows

The MyCaddiPro tee sheet and every department screen as a Windows program: it keeps saving when the internet
is down, and the course's PCs share one copy over the course network.

## Download

**[Download the latest installer](https://github.com/pgatour29-pro/mycaddipro-desktop/releases/latest)**
(Windows 10 or 11, 64-bit, about 125 MB).

## Install

1. Run the installer. Windows shows "Windows protected your PC" once: click **More info**, then **Run anyway**.
2. On the main pro shop PC choose **Main pro shop PC**. Settings shows a 12-character hub code.
3. On every other PC choose **Desk**, pick the main PC from the list and type the hub code.
4. Sign in as usual. The program starts with Windows.

Questions: MyCaddiPro support.
